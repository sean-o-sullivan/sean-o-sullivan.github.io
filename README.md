# Seán's portfolio

Static portfolio published at [sean-osullivan.com](https://sean-osullivan.com/).

## Start here

Read [AGENTS.md](AGENTS.md) before changing or publishing content. Its privacy and
common-sense pass is mandatory regardless of who wrote the draft.

## Site structure

- `index.html`: homepage.
- `projects/`: project pages.
- `tooling/`: tooling writeups.
- `images/` and `thumbnails/`: published media.
- `static/`: shared styles, scripts and navigation.
- `tests/`: existing interaction tests.

GitHub Pages publishes the root of `main`; `.nojekyll` marks the static output.
The working branch may have a different name. Confirm the remote publishing
branch and its current commit before pushing. Check the deployed page afterward.

Private notes and correspondence are research inputs, not publishable copy by
default. Keep them out of this public repository.
